# Artaqy Kids

موقع حضانة Artaqy Kids باللغة العربية مع واجهة RTL، نموذج زيارة يفتح واتساب، قسم أسئلة شائعة تفاعلي، ولوحة تحكم إدارية لإدارة الأسئلة المنشورة.

## التشغيل المحلي

```bash
pnpm install
pnpm check
pnpm build
pnpm test
```

يتطلب التشغيل الكامل متغيرات البيئة التي يوفرها Manus، خصوصًا `DATABASE_URL` وبيانات Manus OAuth. المسار العام هو `/`، ولوحة إدارة الأسئلة هي `/admin/faq`. الوصول إلى لوحة الإدارة يتطلب تسجيل الدخول بحساب له صلاحية `admin`.

## قاعدة البيانات

جدول `faqs` يحتوي على السؤال والإجابة والفئة والأيقونة وترتيب العرض وحالة النشر. المهاجرة الأولى موجودة في `drizzle/0000_ambitious_doctor_octopus.sql` وتم تطبيقها على قاعدة بيانات المشروع. لا تُخزّن أسرار أو ملفات `.env` داخل المستودع.

## النشر إلى Vercel

يعمل workflow الموجود في `.github/workflows/deploy-vercel.yml` عند كل push إلى `main` أو عند تشغيله يدويًا. يجب إضافة أسرار المستودع التالية في GitHub تحت **Settings → Secrets and variables → Actions**:

- `VERCEL_TOKEN`
- `VERCEL_ORG_ID`
- `VERCEL_PROJECT_ID`

تم إعداد `vercel.json` و`api/index.ts` لتشغيل الواجهة وواجهة tRPC في نشر Vercel واحد. تظل استضافة Manus الحالية هي النسخة المنشورة المُدارة من المشروع، بينما Vercel هو مسار النشر الخارجي المطلوب عبر GitHub Actions.

## ملاحظات الإدارة

المستخدم المالك الذي يطابق `OWNER_OPEN_ID` يحصل تلقائيًا على دور `admin` عند تسجيل الدخول. يمكن تحديث محتوى FAQ من لوحة الإدارة دون تعديل الكود، مع دعم النشر والمسودات والحذف والتعديل.
